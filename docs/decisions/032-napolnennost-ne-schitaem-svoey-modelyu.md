Промпт опознания (`counting/identify.py`) не спрашивает наполненность салона.
Колонку I бланка заполняет только выгрузка оператора (`operator.py`, графа G),
где для строки есть запись; иначе колонка остаётся пустой.

## Почему

Решение владельца, а не результат замера: строить отдельный счёт наполненности
по кадру — заметный объём работы (промпт, шкала таблицы 1, проверка на
реальных кадрах), а видно ли вообще салон сквозь стекло с К2/К3 под нужным
углом, не измерено. Госномер и маршрут инструкция требует обязательно и без
запасного источника; наполненность у оператора уже есть в части строк —
дублировать её своей моделью раньше проверки самой возможности не стали.

## Что отсюда следует

`Occupancy` в `DeliveryRow` остаётся: значение приходит из `operator.py`, а не
из ответа модели опознания. Если заказчик потребует наполненность и там, где
оператор её не отметил, вопрос открывается заново — сначала измерить
читаемость салона на боевых кадрах, потом решать про промпт.
