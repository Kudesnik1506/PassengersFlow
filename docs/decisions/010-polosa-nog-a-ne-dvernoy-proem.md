Размечать дверь по полосе ног (0.65–1.12 высоты кузова), а не по дверному проёму.

## Почему

Счёт идёт по точке опоры — низу рамки человека, то есть по тому, где стоят ноги.
Замер по набору: 7116 наблюдений, десятый процентиль точки опоры 0.66 высоты
кузова, медиана 1.12. Низ зоны обязан выходить ниже рамки ТС: ноги стоящего у
двери оказываются ниже её нижней границы.

Оба края этой ошибки уже стоили по полдня. Зона, нарисованная по проёму (низ
0.80–0.91), дала на видео 09 **ноль событий** — прогон при этом не падал. Зона,
поднятая выше 0.65, начинает ловить пассажиров, стоящих в салоне и видимых сквозь
дверь: на 09 это дало ложное срабатывание, на видео 15 — 8 входов и 15 выходов
там, где через двери не прошёл никто.

Значение по умолчанию в `DoorSpec` тоже приведено к этой полосе: фолбэк работает
на любой записи без разметки, то есть на первой боевой.
