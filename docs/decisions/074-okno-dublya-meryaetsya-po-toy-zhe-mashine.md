Окно повторного нажатия — пять минут, и сверка внутри него идёт по ПОЧИНЕННОМУ
бортовому номеру.

## Почему не минута

Прежние 60 с брались от медианы интервала между прибытиями (80 с). Величина не
та: дубли ищутся по бортовому номеру, и две разные машины не столкнутся, как бы
плотно они ни шли. Значение имеет расстояние между двумя НАСТОЯЩИМИ заездами
одного борта — а это два часа.

Замер по суткам: 51 пара одного борта лежит в пределах 63 секунд, следующая —
через два часа, между ними пусто. Минута обрезала полосу по краю и пропускала
борт 38427: два нажатия с разницей 63 секунды, тот же маршрут, исправленная
наполненность. Автобус за минуту не возвращается.

## Почему после починки полей

Личность машины известна только после `repair`. Оператор путает борт с
маршрутом, и по напечатанному две записи одной машины выглядят разными бортами,
а две разные машины, у которых в графу борта попал один номер маршрута, —
одной. Живой случай второго рода: строки 2482 и 2668, обе с «бортом 225»,
на деле разные машины 38201 и 38207 на маршруте 225. Их развело только
расстояние в 34 минуты; попадись они ближе — слились бы молча.

## Цена

Снятых строк 51 вместо 50. Из книги они не выбрасываются — метятся
розовым (решение 075).
