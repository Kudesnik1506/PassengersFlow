Репозиторий открыт сознательно — это цена за настоящую защиту ветки.

## Почему

На бесплатном тарифе личного аккаунта защита веток и rulesets приватным
репозиториям недоступны. Без них запрет `--no-verify` остаётся договорённостью, а
не механизмом: локальный хук этот флаг не перехватывает, git при нём просто не
запускает хук.

Публикация безопасна по составу — проверено аудитом всей истории перед открытием:
ни почты, ни локальных путей, ни ключей; имя заказчика в текстах не встречается ни
разу, только обезличенное «заказчик». Кадры, веса, кэш и результаты прогонов не
версионируются.

Следствие для повседневной работы: прямой push в `main` отклоняется, публикация
идёт через ветку и перемотку на проверенный коммит.
