# Действующие запреты

Читается автоматически. Здесь только то, что уже проверено и стоило времени —
обоснования в `docs/decisions/`, правила приёмки в [PRINCIPLES.md](PRINCIPLES.md).

1. **Планка 10 % не снижается.** Корректировка идёт по боевым записям, не по
   отладочному набору. Отменить может только заказчик.
2. **Детектор менять бесполезно** — проверено сравнением трёх моделей.
3. **Покадровый bbox транспорта не использовать** — только канонический по окну.
4. **Зона двери — полоса ног, а не дверной проём** (0.65–1.12 высоты кузова).
5. **Ослаблять сшивку треков бесполезно** — проверено развёрткой по набору.
6. **Симметричную ветку `resolve_disappearance` не делать** до расширения эталона.
7. **Наружу уходят числа, не кадры.** Лица и номера машин не публикуются.
8. **Сначала тест, потом код** — тест обязан падать по той причине, ради которой
   делается правка.
9. **Порог из `settings.py` не копировать** — импортировать.
10. **Не выдумывать тест ради заполнения `verify`** в записи решения.

## Прежде чем делать

Собираетесь менять поведение — сначала поиск по памяти решений:

```bash
grep -rl "<тег>" docs/decisions/          # трекинг, дверные-зоны, метрика, ...
grep -rl "появились боевые записи" docs/decisions/   # что пересмотреть при новых данных
```

Каталог записей — [docs/decisions/README.md](docs/decisions/README.md),
он генерируется гейтом, руками не правится.

## Когда заводить запись

Запись оправдана, только если существует правдоподобное будущее действие, которое
она **запрещает или перенаправляет**. Текущие метрики, инструкции и структура
каталогов записей не порождают — им место в README.

Запись уходит **тем же коммитом, что и реализация**. Досочинённая в конце сессии
запись — это реконструкция, а реконструкции здесь уже давали неверное «почему».

Пересказывать принципы из PRINCIPLES.md в записях запрещено: принципы — правила
впредь, записи — единичные выборы.

## Ограничение на этот файл

Не длиннее ~30 строк запретов. Новый запрет входит, вытесняя старый в каталог:
то, что не прочитывается целиком, не работает вовсе.
