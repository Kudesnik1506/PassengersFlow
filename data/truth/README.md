# Эталон

Черновик составлен покадровым просмотром (`tools/strip.py`), проверка за заказчиком.
Колонка `confidence`: high — событий мало и они однозначны; medium — есть неоднозначность,
описанная в `note`.

Главное, что показал просмотр: **три ролика из пяти содержат ноль событий**. Это не
дефект разметки, а свойство найденного материала. Такой набор измеряет в основном
точность в смысле «не насчитать лишнего», а не полноту.

Ещё одно наблюдение, важное для боевой съёмки: в ролике 03 дверь маршрутки обращена
от камеры, и посадку не видно в принципе. Никакой алгоритм это не вытянет — камера
должна смотреть на ту сторону ТС, где двери.
